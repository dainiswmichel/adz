It is reasonable to want to know exactly what a plugin does with data before installing it. This page states it plainly.

By default, nothing leaves the site

On a fresh installation, adz.world connects to no external service. The site serves only the adz created on it, and no reader data leaves the server. Every connection described below is off until a site administrator switches it on deliberately.

What a reader's browser holds

If a reader writes what they are shopping for, that text is held in their own browser. It is not an account. It is not sent to adz.world. Clearing site data removes it entirely. A reader who writes nothing is tracked by nothing, and the invitation panel is not a prerequisite for reading anything.

Advertising networks a site connects itself

When a site administrator enters their own account details for a network and enables it, that network's script runs in the reader's browser, loaded from the network's own servers. The network therefore receives the reader's IP address, user agent and the page address, and may set its own cookies, under that network's terms rather than this plugin's.

The plugin sends the network only the account identifiers the administrator entered. It does not add anything about the reader, and it does not alter the unit the network returns.

Affiliate networks a site connects itself

An affiliate network is likewise off until the administrator saves their own identifiers. Once enabled, the plugin places a link in the page. Nothing is sent to the network until a reader follows that link, from their own browser.

The link carries the site's own identifiers and, for search-based networks, the category and refinement the reader typed. That is the point of it: the reader's request is what makes the result relevant.

Creatives are never modified

What a network returns is presented exactly as that network built it. The plugin does not resize it, crop it, restyle it or constrain it. This is not only courtesy: a modified or clipped unit breaks the network's terms, and the publisher carries that, not the plugin.

It also means the plugin defends the slot. Many themes apply rules that would silently resize an advertisement; the slot is built so neither the theme nor the plugin can reach the creative.

Where to read the detail

The full list of external services, what each receives and when, with links to each provider's own terms and privacy policy, is in the Privacy Policy.
