adz.world is a WordPress plugin for running permission-based advertising alongside whatever advertising a site already carries.

The premise

Advertising does not have to be built on surveillance. A person who wants to buy a couch will say so, given somewhere to say it, and what they say will be more accurate than anything inferred from watching them. The infrastructure required to ask is far smaller than the infrastructure required to guess.

That is the whole idea. Everything else is implementation.

What the project is not

It is not an ad blocker, and it is not an argument that publishers should earn less. Publishers need revenue, and a system that ignores that is a hobby rather than a proposal.

It is not a replacement for existing networks either. It is designed to sit beside them so a site can adopt it without risk.

Open source

The plugin is licensed under the GPLv3 and distributed through the WordPress plugin directory. The source can be read, audited and forked by anyone, which is the appropriate standard for software that sits between a publisher and their readers.
