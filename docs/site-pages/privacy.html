The short version

By default the plugin sends nothing anywhere. A site serves only the adz created on it, and no reader data leaves that site's own server. Everything described below happens only after a site administrator has switched a specific feature on.

What a reader's browser stores

If a reader fills in what they are looking to buy, that preference is held in their own browser. It is not an account, it is not sent to us, and clearing site data removes it. A reader who writes nothing is tracked by nothing.

If a site connects to the adz.world network

This is off unless an administrator enables it under Adz.world › Connections. With it on:

  • When a reader is shown an adz, the site sends us its publisher ID and access tokens, its referral code, and the reader's IP address, so that we can return an adz and avoid repeating one the reader has already seen.
  • When an adz is published or deleted, its title, content and categories are sent.
  • When a site registers, its URL, title and administrator email address are sent.
  • If an administrator opts in to earnings statements, an explicit statement request sends a publisher ID and a read-only token, and the requesting server's IP address is received. No earnings request is made automatically.

We use this to deliver and account for advertising. We do not sell it, and we do not build advertising profiles of readers from it.

Advertising providers a site connects itself

Each provider is off until a site administrator enters their own account details and enables it. Once enabled, that provider's script runs in the reader's browser, loaded from the provider's own servers. The provider therefore receives the reader's IP address, user agent and the address of the page being viewed, and may set or read its own cookies, under its terms and not ours. The plugin sends the provider only the account identifiers the administrator entered.

Media.net, Amazon Publisher Services and Ezoic are listed in the plugin with a link to their own sign-up. The plugin stores no credentials and loads no script for those three, and does not contact them.

Affiliate networks a site connects itself

An affiliate network is off until an administrator saves their own identifiers and enables it. The plugin then places a link in the page. Nothing is sent to the network until a reader follows that link, from their own browser; the plugin itself makes no request to any affiliate network, and no affiliate link is produced on activation.

The link carries the site's identifiers and, for the search-based networks, the category shown on the page plus any refinement attached to it. The networks with a link builder are Amazon Associates, Walmart Affiliates through Impact, Awin, CJ Affiliate, Rakuten Advertising, the eBay Partner Network and ClickBank. For ClickBank the link is a HopLink built from the account nickname, the vendor nickname and an optional tracking id; nothing a reader typed is ever added to it. ClickBank's Client Contract and Privacy Policy apply to what happens after the link is followed.

This website

adz-world.com runs WordPress. Our hosting provider records standard server logs, including IP addresses, for security and diagnostics. If you choose a visual theme using the control on this site, that choice is stored in your own browser and is not sent to us.

Keeping and deleting

We keep network and earnings records for as long as an account is active and for as long afterwards as accounting and tax law requires. Disconnecting a site removes its stored token and stops delivery and synchronisation.
