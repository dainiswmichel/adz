Platform Compliance

adz.world is distributed as a WordPress plugin and runs alongside third-party advertising networks. This page states how it meets the requirements of those platforms.

WordPress.org

  • Licensed under the GPLv3, with full source readable in the plugin directory
  • All output escaped where rendered; all input sanitised and validated against an allowlist
  • Administrative actions require both a capability check and a nonce
  • Database queries are prepared; no request value selects which option is read or written
  • No PHP file executes when requested directly
  • Every external service is disclosed in the readme and in our Privacy Policy

Advertising Networks

Where a site owner connects a network, the plugin builds that network's unit from the identifiers the owner entered. It does not paste or execute third-party script written by anyone else.

What a network returns is rendered exactly as that network built it. It is not resized, cropped, restyled or clipped, because a modified or obscured unit breaches network policy. Many themes ship rules that would silently resize an advertisement; the slot is built so neither the theme nor the plugin can reach the creative.

Networks prohibit serving into a hidden container. Carousel formats hide inactive slides, so a rotation carrying a network unit should use the Single format.

Site Owner Responsibilities

You hold your own accounts with each network and accepted their terms. The plugin cannot accept terms on your behalf, create accounts, or certify that a placement is approved. Where your jurisdiction requires consent before third-party advertising scripts run, obtaining it is handled by your consent management platform, not by this plugin.

Reporting

Security issues and compliance concerns can be raised through the platform. Security reports are acted on before feature work.
