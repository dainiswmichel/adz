== Version Number Format (Notation: A.B.C.D) ==

* "A" releases are "Major Releases" - new features, optimizations

* "B" releases are "Minor Releases" - optimizations, fixes

* "C" releases are “Housekeeping Releases" - fixes, bugfixes, coding enhancements

* "D" releases are “Premium Version Releases” in which all features of the latest free version are incorporated into the premium version




== Change Log ==

= 1.1.0 =
* Candidate only. Not a WordPress.org release and not an activation claim.
* Outbound network calls require the existing network switch and a separate monetization acceptance. Activation does not call out.
* Rotation option names from requests must match adz_rotation_<digits> before they are read, updated, or deleted.
* Registration reset is an authenticated admin action with its own nonce. The public hook is removed. Unknown template names on the ad request return continue.
* Template includes stay inside adz-templates. Template chrome is escaped. Template settings use one option.
* Ad-view selects use prepared queries. The unused concatenated condition string is removed.
* Admin Ajax URLs in js/plugin.js and vendor/eof/js/eof-custom.js come from wp_localize_script.
* Earnings screen lists statement buckets and shows them as unconfigured. It does not rewrite ad links or replace a publisher referral code.
* The audience words stack, and access remains on top. Visit, guest, and member are added under access. An unknown human is also a visit. A known human is an access, a visit, and a guest. A member is a guest who has made an adz-world purchase. A bot cannot be a guest or a member, and can access the site as either. An access with no profile uses a session cookie. This candidate does not record a purchase and does not decide that an access is human.
